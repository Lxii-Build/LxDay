# 0821 轮 · 真机自测清单

按顺序走一遍，大约 15 分钟。**打 ✗ 的地方直接把编号告诉我**，不必描述细节。

前置：
1. 服务器 `docker compose pull && docker compose up -d`（后台是 `go:embed` 进二进制的，
   不拉新镜像看到的还是旧后台）
2. 装本轮的 Debug APK（版本仍是 1.0.0，未发 release）
3. **先去「我的 → 同步自检」把标红的项目开全**，否则后面 4、5 两组必然不准

---

## 一、崩溃与状态历史（本轮最优先）

| # | 操作 | 预期 |
|---|---|---|
| 1.1 | 我的 → 伴侣状态历史 | **不再崩溃**（这是本轮头号问题） |
| 1.2 | 该页顶部切换「我 / 对方」 | 两边都能出数据；此前这页显示的其实一直是你自己的记录 |
| 1.3 | 切到「电量曲线」 | 有横纵坐标轴与时间刻度（此前是一条光秃秃的折线） |
| 1.4 | 点「选择日期」 | 是年月日三列**滚轮**，不再是 ±1/±7/±30 天的步进按钮 |
| 1.5 | 滚到底自动加载后，故意断网再滚 | 出现「加载更多」可点重试，不再一次网络抖动就再也拉不到 |
| 1.6 | 查今天的记录 | 当天凌晨 0~8 点的记录也在（此前时区错位会把它们算进"昨天"） |

## 二、相册（本轮改动最大）

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 发现 → 相册 | 顶部三个按钮；「回收站」若有内容会带数字角标 |
| 2.2 | 看相册卡右侧 | 有「⋯」按钮。**此前只能长按且界面上零提示**，这就是你以为"分组删不掉"的原因 |
| 2.3 | 点「⋯」→ 删除相册 | 确认按钮是**红色**、取消是灰色，且红按钮有 1 秒才可点（防手滑连点） |
| 2.4 | 点「未归类」的「⋯」 | 能改名；**没有删除选项**（它是系统分组，删了照片无处安放） |
| 2.5 | 进相册 → **长按任一张照片** | 进入多选态，顶栏变「已选 N 张」，底部出现「移动到…」与红色「删除」 |
| 2.6 | 多选几张 → 删除 | 二次确认后进回收站 |
| 2.7 | 多选几张 → 移动到… | 能移到别的相册或「未归类」 |
| 2.8 | 大图页点删除图标 | **有二次确认**（此前点一下就删，误触零成本） |
| 2.9 | 大图页看顶栏 | 相册内的照片有「设为封面」按钮（接口一直有，此前没入口） |
| 2.10 | 点开大图 | **秒出**（先加载 1080 预览），双指放大后才拉原图 |
| 2.11 | 左右滑动翻页 | 相邻两张已预加载，不再每次白屏等下载 |
| 2.12 | 回收站 | 每张显示「还剩 N 天自动删除」，≤3 天转红；有「彻底删除」与「清空回收站」 |
| 2.13 | 彻底删除一张 | 确认框明说"永久删除、无法恢复"；删完服务器磁盘文件也没了 |
| 2.14 | 新绑定一对账号（如方便） | 相册里自动有「我们 / 日常 / 旅行」三个默认分组 |

## 三、上传与选图（"图片消失"的修复）

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 相册 → 上传 → 看选图器顶部 | 有可横滑的分桶：全部 / 相机 / 截屏 / 微信 / 下载…（学 QQ） |
| 3.2 | 切到「截屏」 | **能看到截图**。此前你手机图片超 2000 张时，截图与微信图会被整批截断，一张都看不到 |
| 3.3 | 往下滚 | 分页加载，进页面不再先卡两三秒 |
| 3.4 | 点格子右下角的放大角标 | 弹出大图预览，可在预览里直接选中/取消 |
| 3.5 | 一次选 20~30 张上传 | **能成功**。单次上限已从 20 提到 100 |
| 3.6 | 若有失败 | 卡片上可展开「查看失败原因」，逐张写明具体原因；可重试的项有「重试失败项」按钮 |
| 3.7 | 传一张 HEIC（相机开「高效格式」拍的） | 能成功 |
| 3.8 | 传一张动态 WebP | 保住动画（此前会被压成静图） |
| 3.9 | 看自己刚传的照片 | 秒开（直接读本机原图，不走网络） |
| 3.10 | 我的 → 编辑资料 → 点头像 | 用的是**和相册一样的选图器**，选完进**圆形裁剪页**可拖动缩放 |

## 四、状态同步（"总是显示不好"的修复）

| # | 操作 | 预期 |
|---|---|---|
| 4.1 | 主页看伴侣状态卡底部 | 有「更新于 X 分钟前」，会自己走字 |
| 4.2 | 让对方断网 10 分钟以上 | 卡片**置灰**且提示「可能已过期」；超过 1 小时显示「状态未知」而不是继续展示旧值 |
| 4.3 | 对方按 Home 回桌面 | 你这边不再显示「正在使用微信」，改为「息屏/无前台」 |
| 4.4 | 对方息屏 | 立刻变息屏，且前台应用清空（此前会一直挂着息屏前那个应用） |
| 4.5 | 对方开着 AOD（息屏显示） | 算「息屏」而不是「亮屏」 |
| 4.6 | 对方重启手机后不解锁 | 首次上报就是"息屏"（此前初值写死 true，必然先报一次错的"亮屏"） |
| 4.7 | 对方进电梯/地铁再出来 | 状态能补上（WS 断线时走 HTTP 兜底，此前整段时间的采集都被丢掉） |
| 4.8 | 我的 → 同步自检 | 逐项显示"已开启/待开启"，每项写明"不开会怎样" |

## 五、观感统一（miuix）

| # | 操作 | 预期 |
|---|---|---|
| 5.1 | 进任意列表页并立刻下拉 | **只有一个加载圈**。此前首屏圈与下拉圈会同时转——这就是你说的"两个加载并存" |
| 5.2 | 通览各页图标 | 全是 miuix 风格，没有粗细不一的 Material 图标混在里面 |
| 5.3 | 冷启动（先杀进程） | 第一帧的底色与主界面一致，不再闪一下浅灰/白 |
| 5.4 | 让对方发「紧急找你」 | 响铃全屏页是 miuix 观感；**功能优先**，万一渲染异常会回退成朴素布局但一定能停下响铃 |
| 5.5 | 随便点几个弹窗 | 取消一律灰底在左、确认蓝色在右；删除类确认一律**红色** |

## 六、后台（手机浏览器打开）

用手机浏览器访问 `https://love.lxii.cc/`：

| # | 操作 | 预期 |
|---|---|---|
| 6.1 | 登录后看任意列表页（如网络日志） | 不是挤成一团的表格，而是**一行一张卡**，不需要左右横滑 |
| 6.2 | 搜索区 | 输入框一行一个、撑满宽度，不再挤爆 |
| 6.3 | 划到页面底部 | 按钮不被曲面屏底部手势区遮住 |
| 6.4 | 侧边菜单 | 新增「相册管理」与「磁盘统计」两项 |
| 6.5 | 磁盘统计页 | 能看到全站照片数、原图占用、**磁盘实际占用**、回收站占用，以及各情侣的占用明细 |
| 6.6 | 系统设置页 | 除站点/SMTP 外，多出「相册与上传 / 安全与限流 / 数据保留 / 互动冷却」四个分区 |
| 6.7 | 改一个配置（如每日上传张数）并保存 | **立即生效，不用重启容器** |
| 6.8 | 点某分区的「恢复默认」 | 该分区值回到默认 |
| 6.9 | 内容审核 | **没有「日记」tab 了**；仪表盘也没有"日记总数"卡 |

## 我这边已经验证过的（不用你重复）

- Go：`vet` + 全部单测通过（新增 21 个，含"NULL 列不再崩"、"并发配额不被击穿"、
  "清理 SQL 真的删到行"、"HEIC/AVIF/BMP/GIF 端到端真解码"）
- Android：`compileDebugKotlin` 通过 + 185 个单测全绿（含"4000×3000 解码内存 45.8MB→12.0MB"、
  "2000 张老图 + 5 张新截图不被截断"、"回桌面不再显示上一个应用"、"AOD 不算亮屏"）
- 后台：`npm run build` 通过；Playwright 在 412/360/390/768 四档视口逐页跑过，
  12 个页面全部无横向溢出、无控制台错误、无失败请求、非白屏
- 生产 502 的根因用真实请求在 love.lxii.cc 上实测确认过（≤1MB 回 403、≥2MB 变 502）

## 我这边**无法**验证的（只能靠你）

- 真机观感（miuix 是否真的统一、图标是否别扭、裁剪页手感）
- 双机实时时序（状态同步延迟、响铃能否停下、静默通知会不会吵）
- 你手机上那 2000+ 张图里，截图/微信图是否真的都能扫到了
- 一加 ColorOS 的后台冻结是否还会打断同步（这取决于自检页那几项开没开）
