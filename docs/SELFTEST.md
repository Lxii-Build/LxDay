# 发布前验收清单

这份清单用于每次发布前的实际验收。自动化测试不能代替 Android 真机和浏览器操作；未验证的项目必须明确记录，不得写成“已通过”。

## 服务端与镜像

- [ ] `gofmt -l .` 无输出。
- [ ] `go vet ./...` 通过。
- [ ] `go test -timeout 400s ./...` 通过。
- [ ] 新库启动成功，`/healthz` 返回 200，`/readyz` 在目录不可写时返回非 200。
- [ ] 从旧 schema 升级的临时 SQLite 库启动成功，补列和索引均存在。
- [ ] 未绑定用户、跨 pair 用户、禁用用户和过期令牌均不能读取私密资源。
- [ ] `/media/<id>`、缩略图和预览图鉴权有效；公开上传路径不包含私密相册文件。
- [ ] 上传合法图片、超大图片、超像素图片、GIF 帧炸弹和损坏文件都得到可理解的结果，服务没有 OOM 或长时间无响应。
- [ ] 容器使用非 root 用户，数据、公开资源和私密媒体目录重启后仍存在。

## 后台浏览器

- [ ] 登录失败、禁用账号和错误密码的响应无法区分原因。
- [ ] 首次登录能完成改密；登出后令牌不再发送；浏览器关闭后后台会话消失。
- [ ] 用户页可编辑、封禁、解封和删除，并显示成功/失败结果。
- [ ] 关系页可查看状态、取消待处理邀请和解绑，邀请码本身不出现在列表响应。
- [ ] 相册、内容审核、APP 版本、通知、存储、系统设置、审计和网络日志页面都能加载。
- [ ] 危险操作有明确后果、取消与确认颜色不同、请求中不能重复提交。
- [ ] 以手机、窄屏和平板视口运行 `admin/scripts/mobile-audit.mjs`，无白屏、横向溢出、控制台错误和未处理 4xx/5xx。
- [ ] 更新页面在同一更新流同时显示正式版和 prerelease，日志正文可滚动但底部取消/更新按钮固定；无更新时更新按钮不可用。

## Android 真机

- [ ] 安装、升级和卸载行为符合当前签名配置；升级不会因 versionCode 或签名错误失败。
- [ ] 注册、登录、绑定和双方知情授权流程可完成；默认开启状态共享时启动后无需重复点设置。
- [ ] 状态共享开关关闭后停止采集和同步，重新开启后恢复；权限逐项拒绝不会让应用闪退。
- [ ] 前台、后台、息屏和 AOD 状态显示合理；WebSocket 断线后能重连并通过 REST 兜底。
- [ ] 求陪伴、求冷静和响铃按钮再次点击能及时撤回；通知和本地响铃也能停止。
- [ ] 待办的一次、每天、每周提醒和删除/完成行为正确。
- [ ] 相册多图可左右滑动查看，缩略图失败有可见占位，上传失败可重试且不会无限占用内存。
- [ ] 二级页系统返回和手势返回都回到上一级；页面切换使用统一的返回动画。
- [ ] 更新弹窗显示新版本号、发布时间、历史 `CHANGELOG.md` 内容；按钮固定在正文外侧，下载链接可用。
- [ ] 令牌存储为 Keystore 加密数据，APK 和日志中没有共享通讯密钥。

## 发布记录

填写版本、提交短 SHA、测试设备/浏览器、未验证项和回滚 tag。生产部署前备份 SQLite 与两个媒体卷，部署后再次检查健康、就绪、登录、WebSocket 和相册读取。
