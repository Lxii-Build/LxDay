# 林曦日记 · 应用介绍

> 面向使用者的介绍，供 GitHub Release 正文引用。开发者向的工程说明见仓库 `README.md`，
> 逐版本变更见 `CHANGELOG.md`。

## 一句话介绍

林曦日记（LxDay）是一款**只给两个人用**的情侣 App：实时共享彼此的手机状态，
把照片存进只有你们能看的相册，用待办互相提醒，用轻互动传递牵挂。

自托管——服务端跑在你自己的服务器上，数据不经过任何第三方。

## 它能做什么

- **共同相册**：一次最多传 100 张，可以建分组（绑定时自动建好「我们 / 日常 / 旅行」）、
  改名、批量移动与删除。支持评论和点赞，「这一天」能翻出往年今天拍的照片。
  删掉的照片进回收站，能恢复、能彻底删除，每张都写着还剩几天自动清理。
  自己传的照片直接读手机里的原图，不耗流量也不用等。
- **实时状态共享**：互相可见电量与充电状态、亮屏 / 息屏（能区分息屏显示 AOD）、
  正在使用的应用、正在播放的音乐、网络与 WiFi。
  主页会写「更新于 N 分钟前」——数据过期会置灰，对方失联时不会把旧状态当成现状给你看。
- **伴侣状态历史**：按天翻对方的状态时间线与电量曲线。
- **待办与提醒**：给自己或对方加待办，可选「仅一次 / 每天 / 每周指定几天」循环提醒。
  重要的事可以开强提醒（走闹钟音量，静音也能听见），不想被吵时可以单独把某条的提醒关掉。
- **远程互动**：一键发「求陪伴 / 求冷静 / 响铃提醒」。响铃 7 秒自动停，
  发错了可以撤回，对方也能一键停止。
- **恋爱天数与资料**：设纪念日、头像（可圆形裁剪、拖动缩放）、昵称、性别、简介，
  主页显示在一起的第 N 天。
- **同步自检**：一页列出所有影响后台运行的权限，逐项告诉你当前状态**以及不开会怎样**，
  点一下直接跳到对应的系统设置。
- **应用内检查更新**。

## 隐私

这是两个人的私密数据，所以有几条是硬性的：

- **状态共享需要双方明确同意才开启**，同意前不采集、不上传。
  可以随时在「我的」里关掉，关掉立即停止采集与同步。
- **相册照片只有你们两人能看**。照片地址是带鉴权的代理形态，
  拿到链接的人没有你们的登录凭据也打不开；照片的真实存放路径不会离开服务端，
  也不会被写进任何日志。
- 服务端运营后台（给你自己管服务器用的）只能看到 384 像素的缩略图、
  永远拿不到原图，且每次查看都留审计记录。
- 「正在使用的应用」需要系统的「使用情况访问」权限。**不给这个权限其它功能照常用**，
  只是这一项显示不出来。

## 需要哪些权限

App 会在用到时才申请，都可以拒绝，拒绝后只影响对应的那一项：

- 通知：伴侣状态变化与待办提醒
- 照片和视频：选图上传（也可以走系统相册选择器，那种方式不需要授权）
- 精确闹钟：待办的定时提醒
- 后台运行 / 电池优化白名单：状态能持续同步
- 使用情况访问：显示「正在使用的应用」

## 平台与部署

- 客户端：Android（Kotlin + Jetpack Compose，miuix HyperOS 风格）
- 服务端：Go + SQLite 单容器，自带运营后台，Docker Compose 一键部署
- 开始使用：注册 → 用邀请码与伴侣绑定 → 完成知情同意 → 开始共享
