# 林曦日记 · 应用介绍（首发）

> 本文件为应用首次发行时的介绍文案，供应用市场 / GitHub Release 正文引用。后续版本的变更记录见 `CHANGELOG.md`。

## 一句话介绍
林曦日记（LxDay）是一款「情侣双人」互动 App：实时共享彼此的手机状态、用待办互相提醒、用轻互动传递牵挂。

## 它能做什么
- **实时状态共享**：在双方知情同意后，互相可见电量与充电、亮/灭屏与锁屏、正在使用的 App、正在播放的音乐、网络/WiFi 等实时状态。
- **伴侣状态历史**：按天查看对方的状态时间线与电量曲线。
- **待办与提醒**：给自己或对方添加待办，支持「仅一次 / 每天 / 每周指定几天」的循环提醒，可开关强提醒（闹钟音量），并可随时用卡片开关暂停提醒。
- **远程互动**：一键发送「求陪伴 / 求冷静 / 响铃提醒」。
- **恋爱天数与资料**：设置纪念日、头像、昵称、性别、简介，主页展示在一起的第 N 天。
- **应用内检查更新**：支持提示新版本与强制更新。

## 隐私说明
- 状态数据**仅在你与伴侣两人之间**传输，需在 App 内完成**知情同意**后才开启共享。
- 可随时在「我的」中关闭状态共享，关闭后立即停止采集与同步。
- 「调试/示例」入口仅用于开发调试，不上传、不参与真实共享。

## 平台与形态
- 客户端：Android（Kotlin + Jetpack Compose，miuix HyperOS 风格）。
- 服务端：自托管（Go 后端 + 内置运营后台），支持 Docker Compose 一键部署。
- 使用方式：注册账号 → 用邀请码与伴侣绑定 → 完成知情同意 → 开始共享。
